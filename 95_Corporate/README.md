# Corporate layer (Phase 3 — do not start until the personal layer is stable)

Goal: extend the same three-file model across the parent organization without disturbing the personal system.

## What goes here
- `CLAUDE.md` — org-wide standing rules (voice, approvals, sensitivities) that apply to every company folder.
- `MEMORY.md` — org-level active index: cross-company initiatives, capital, shared deadlines.
- `Org-Map.md` — every entity, ownership relationships, who runs what.
- `Shared-Skills/` — processes used across companies (board prep, cross-company reporting, hiring).

## How it connects
- Root `CLAUDE.md` gets one added line: "If a task touches more than one company, also read `95_Corporate/CLAUDE.md`."
- Company folders in `20_Companies/` stay where they are. Nothing moves.

## Sharing with others
- Personal folders (`01_Me`, `10_Personal`, `30_People` notes) stay private.
- For a shared corporate system, create a separate shared folder or Cowork Project containing only `95_Corporate/` and the company folders you choose to expose, with its own `CLAUDE.md`. Each person keeps their own personal OS.
