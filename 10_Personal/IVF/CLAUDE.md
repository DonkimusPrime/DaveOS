# CLAUDE.md — IVF

Scope: the IVF process — clinic and provider contacts, cycle history, test results, medication
schedules, appointments, and questions to bring to the next appointment.

This is a health-data folder. Handle it under the same rule as `10_Personal/Health-Fitness/`:
read only what's here, and only when the task is about this workstation.

## Rules
- Work only from what the owner has written in this folder. Never infer a diagnosis, prognosis,
  or success rate. Never fill in a date, dose, count, or figure that isn't already here.
- No medical advice and no interpretation of results. Organising, summarising, and reformatting
  what's written is fine. Anything that reads as a clinical judgement goes to the clinic — capture
  it as a line under "Questions for the next appointment" instead of answering it.
- This folder holds another person's medical information as well as the owner's. Record only what
  the owner enters, attribute each item to whoever it belongs to, and never copy it into another
  workstation, a person file, or an outbound draft without the owner saying so explicitly.
- Copy dates and doses verbatim from the source. If something is second-hand or uncertain, mark it
  `(unconfirmed)` rather than smoothing it into fact.
- Notes go in `Notes/`, one file per appointment or result set. Append to the owner's notes; don't
  rewrite them.
- If the owner writes about how the process is going for them, keep it. Don't editorialise on it
  and don't offer reassurance that wasn't asked for.
