# Health check-in

Trigger: scheduled, or "health check-in."

1. Read `10_Personal/Health-Fitness/MEMORY.md` and this month's log.
2. Ask no more than three questions about the day/period (what was done, how it felt, anything to note).
3. Append the answers to this month's log in `Logs/`.
4. Compare to the current plan in `Plans/`. Note drift in one sentence. Don't lecture; don't set new targets unless asked.
