# Audit reference files

Trigger: monthly (scheduled) or "audit my reference files."

1. Read `01_Me/*`, every `CLAUDE.md`, and `10_Personal/Comms/Voice-Principles.md`.
2. Report, per file:
   - Instructions that contradict another file (quote both, propose which wins)
   - Instructions that duplicate another file (propose the single home)
   - Lines that are vague enough to be unusable ("be professional") — propose a specific rewrite
   - Anything referencing a person, company, or project that no longer exists elsewhere in the system
3. Present as a change list. Apply only what the owner approves.
